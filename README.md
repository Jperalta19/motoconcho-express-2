# Motoconcho Express 2 🛵🇩🇴

Secuela de Motoconcho Express: conduce un motoconcho por tres carriles en Santo Domingo, esquiva las huacas y consigue el mayor puntaje.

## Cómo jugar

Pulsa **¡Arrancamos!**. Usa las flechas izquierda y derecha del teclado o los botones ◀ y ▶ de la pantalla táctil para cambiar de carril. Esquiva los hoyos y recoge:

- 🪙 Monedas: +10 puntos.
- 🍌 Plátanos: +15 puntos.
- 🪖 Casco: absorbe un choque.
- ⚡ Nitro: aumenta la velocidad y te hace invulnerable durante 4 segundos.
- 🧲 Imán: atrae monedas durante 7 segundos.

También ganas puntos por avanzar. Cada 100 puntos subes de nivel: la velocidad y la frecuencia de aparición aumentan, y se anuncia el nuevo nivel. El récord se guarda en el almacenamiento local del navegador. Usa el botón de sonido para silenciar o activar los efectos.

## Tecnología y ejecución

HTML, CSS y JavaScript con **Phaser 3** cargado por CDN mediante una etiqueta `script`, sin compilación ni assets externos. Los gráficos se dibujan mediante Phaser Graphics y los sonidos se generan con Web Audio. Abre `index.html` en un navegador moderno: se necesita conexión para cargar Phaser desde el CDN (salvo que ya esté disponible en la caché del navegador).
